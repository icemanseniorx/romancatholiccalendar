# Roman Catholic Calendar

This repository publishes the subscribed calendar feed for:

**https://romancatholiccalendar.org**

Calendar subscription feed:

**https://romancatholiccalendar.org/calendar.ics**

The calendar follows the supplied printed 2026 traditional Roman Catholic calendar. The printed calendar is authoritative for feast titles, Sundays, ranks, vigils, octaves, fasts, and abstinence. Handwritten annotations are omitted.

Selected notes are drawn only from the supplied:

- Father Lasance Missal
- The Raccolta
- Pilgrim Walks in Rome
- *Lives of the Saints* (compiled from Rev. Alban Butler)

## Updating the feed

Replace `calendar.ics` while keeping the same filename and existing event `UID` values. Commit the replacement to the `main` branch. GitHub Pages will publish the update at the same subscription URL.

## Current release

**Version 1.0.7** retains the vestment colors, date-matched saint lives, and First Friday/First Saturday indications. Every designated Fast, Partial Abstinence, or Complete Abstinence day has an explicit 6:00 a.m. Eastern alert on its all-day calendar entry. On iPhone, subscribers must leave the calendar's “Remove Alerts” setting turned off.
